# People

Typical roles in this space:

- `owner`: primary decision-maker, highest default authority, can change policies and resolve conflicts.
- `member`: regular participant whose preferences, commitments, and routines should be remembered carefully.
- `guest`: occasional participant with limited operational weight.
- `service_bot`: low-authority automation or helper account.

When the real cast changes, prefer active grounding overrides over rewriting this base file immediately.
